## One document, many links

A document can have any number of share links. Create one per audience: one for each investor, counterparty or team. Each link has its own settings and its own stats, so you can see who came through which link and revoke one without touching the others.

Links are not capped on any plan. The Free plan counts shared documents (10), not links.

Every document starts with a **Default link**, created with the document. To add another, open the document and click **New link**.

## Link settings

- **Label**: a private name for the link, such as the recipient. Never shown to viewers.
- **Audience**: an optional private note, such as the person and the deal.
- **Link enabled**: turn the link off to take it offline. Turn it back on any time.
- **Allow download**: whether viewers can download the PDF from the viewer.
- **Let recipients browse versions**: shows viewers a light version history. Pro only.
- **Password**: optional. Any length from 1 to 128 characters.
- **Expires**: optional. The link stops working at the end of that day.

When you create a link you can copy the settings from another link on the same document.

## Passwords

- Set a password on any link. Two recipients of the same document can have different passwords.
- Viewers enter it once; the browser stays unlocked for 14 days.
- Workspace owners and admins can reveal a link's password from the link settings, so you can tell a recipient what it is later.
- Unlocking one link never unlocks another.

## Downloads

If **Allow download** is off, the viewer still shows a Download button. Clicking it lets the viewer request a download by entering their email. You receive an email to approve or deny the request. If you approve, the viewer is emailed a link to download the file or save it into a free lnkdrp account (sign-in required).

## Disabling, revoking and deleting

- **Disable a link** to revoke one recipient's access at once. The document's other links keep working. Re-enable it later if you want.
- **Turn off sharing** on the document to take every link offline in one step.
- **Delete a link** when you will not need it again. Its past views stay in the document's totals. The default link cannot be deleted; disable it instead.
- **Archive the document** to take every link down and free a Free-plan slot. Everything comes back when you unarchive it.

A disabled, expired, archived or deleted link answers exactly like a link that never existed. Nothing about the document leaks, not even its title in a link preview.

## Replacing the PDF

Replace the file from the document page whenever the content changes. Every link keeps working and recipients always see the latest version. Replacing never costs credits. Version history is recorded, and an AI compare of what changed runs when credits allow. See [Credits and plans](/help/credits-and-plans).

## What recipients see

- The viewer opens with the summary and key points, then the document.
- Viewers can scroll all pages, use a grid of page thumbnails, or step through single pages.
- Every page a recipient lands on shows who shared it: the workspace name, or the owner's name if the workspace was never given one.
- If the link has a password, the password screen shows the sender's name and a small preview thumbnail so the recipient knows they are unlocking the right document.
- Viewers can optionally **Introduce yourself** with a name and email, which labels their activity on your side.

## The link URL

Share links look like `lnkdrp.com/s/<id>`. Older links of the form `lnkdrp.com/share/<id>` still work and open the same document.
